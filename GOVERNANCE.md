# Governance

Visual HTML is maintained by the repository owner, who is responsible for review
decisions, release authorization, and repository moderation.

Collaborators propose focused changes through pull requests. Routine fixes need a
clear explanation and appropriate validation. Changes to package boundaries,
security boundaries, or major dependencies need an architecture decision record.
When consensus is unavailable, the repository owner records the decision and its
reasoning in the issue, pull request, or ADR.

Only maintainers authorized by the repository owner may publish packages. Releases
follow [RELEASING.md](./RELEASING.md); a contribution does not authorize a release or
change to repository visibility. There is no promised response time during alpha.

Contributions are provided under the repository's [MIT license](./LICENSE). Preserve
third-party notices when adding or redistributing assets. See the [code of
conduct](./CODE_OF_CONDUCT.md) and [security policy](./SECURITY.md).
