# Support

During private development, repository collaborators can open issues for reproducible bugs, scoped feature requests, and integration questions. Use the integration-question issue form when the existing guides do not answer a question.

Include a reduced HTML example, profile configuration, browser, package versions, and expected behavior. Do not post credentials, private customer templates, or personal data. Follow [SECURITY.md](./SECURITY.md) for suspected vulnerabilities.

Support is best-effort. The repository owner makes maintenance and release decisions as described in [GOVERNANCE.md](./GOVERNANCE.md). Public contact details and any future discussion forum will be announced before the public alpha.
